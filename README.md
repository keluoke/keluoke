# keluoke

I build tools for chess study and game review.

## Diverge

Would you take the rook? After 17. Kf1 in Byrne–Fischer (1956), Maia predicts that a 1900-rated player is most likely to capture on d1. Stockfish prefers Fischer’s 17…Be6. I built Diverge to put those two perspectives on the same board. The studio runs Maia-3 and Stockfish in the browser. The Chrome extension turns static chess diagrams into positions you can explore.
